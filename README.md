# Movie Explorer 🎬 [![Flask](https://img.shields.io/badge/Flask-3.0.2-000000?logo=flask)](https://flask.palletsprojects.com/) [![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python)](https://www.python.org/)

Aplicación web para explorar películas usando la API de TMDB. Perfecta para demostrar habilidades en desarrollo Full-Stack con Python/Flask.

![Demo Screenshot](screenshots/demo.png) <!-- Crea una carpeta screenshots con imágenes tuyas -->

## 🚀 Características Destacadas
- 🔍 Búsqueda en tiempo real de películas
- 🎥 Detalles completos con reparto y recomendaciones
- 🌐 Internacionalización (español/inglés)
- 📱 Diseño responsive
- 🔒 Manejo seguro de API Keys

## ⚙️ Tecnologías
- **Backend**: Python, Flask
- **Frontend**: HTML5, CSS3
- **API**: The Movie Database (TMDB)
- **Herramientas**: Git, dotenv, requests
